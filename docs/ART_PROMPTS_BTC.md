# BTC Homestead — ChatGPT image prompt pack

Copy-paste ready, in the order you'll actually use them. Explanation and the
threshold table are further down — skip straight to step 1 if you just want to go.

---

## Step 1 — create the Project

In ChatGPT: **New Project** → name it `Dream DCA Art` → open its **Instructions** field
→ paste this whole block in:

```
We're going to build a single evolving scene for a cozy pixel-art homestead game, in
the style of a hand-painted top-down/isometric farm-sim (think Stardew Valley key art,
but more painterly/detailed — soft pixel shading, warm lighting, no anti-aliasing blur).

Fixed rules for every image in this project, forever:
- Same camera angle: elevated 3/4 top-down view, slightly isometric, looking down at
  roughly 35-40 degrees.
- Same framing: a portrait-oriented scene (taller than wide), house positioned in the
  upper-middle third, open grassy foreground.
- Same light direction: sun from the top-left, soft warm golden-hour light, consistent
  shadow direction on every object.
- Same colour palette family: warm greens for grass, warm browns for wood/dirt, one
  gold/amber accent for anything BTC-related (signposts, chests, doors). No neon, no
  cool sci-fi colours.
- Pixel-art / painterly-pixel style throughout — visible brush/pixel texture, not a
  smooth photo-real render.
- No text, no UI, no numbers, no HUD baked into the image — just the scene itself.

Whenever I say "using the attached image, make ONE change, keeping everything else
pixel-for-pixel identical in position, lighting and style" — do exactly that: edit the
attached image, change only what I describe, and don't redraw or shift anything else.
```

## Step 2 — start a chat inside that project, send this first

```
Generate the base scene: a bare, empty grassy plot of land, mostly open and undeveloped.
A worn dirt path curves from the bottom of the frame up toward the empty centre, where
a house will eventually stand — leave that spot open and grassy for now. A few trees
along the left and right edges of the frame. A small pond or stream in the lower-left,
with a bit of reed/grass around its edge. Nothing built yet — no house, no fences, no
animals, no chests. Just quiet, undeveloped land waiting for its first owner.
```

Save what comes back as `stage_00.png`.

## When you're done

Send back `stage_00.png` through `stage_17.png` (18 files). The % / BTC / sats numbers
above go straight into `src/data/progression.json` as the real thresholds — don't
renumber them without saying so, since the code will point at these exact values.

Animation (trees swaying, the upgrade moment having a little flourish) is **not** part
of this pack — that's handled entirely in code once the art is in, no extra images
needed for it.

## Notes

- **Steps 2, 7, 12, 17** are the only ones that must land in *exactly* the same
  footprint every time — those four are the actual house-upgrade stages (0/1/2/3/4 in
  `progression.json`). Everything else (garden, coop, dog, cow, chests, vault, dock,
  villagers, citadel glow) is an independent layer that gets composited on top of
  whichever house stage is current.
- If a step drifts (house moves, lighting changes), redo just that one step from the
  last **accepted** image — don't restart the whole chain.
- Keep everything in **one chat**, inside the `Dream DCA Art` project, start to finish.
  A new chat loses the image-to-image continuity even with the project instructions
  attached, because those set style rules, not visual memory of the last image.
